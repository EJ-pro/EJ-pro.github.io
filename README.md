# 이재희 포트폴리오

AI Agent / RAG Engineer 포트폴리오입니다. Next.js App Router를 사용하고 GitHub Pages에 정적 사이트로 배포합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

`http://localhost:3000`에서 확인할 수 있습니다.

## 검증

```bash
npm run check
```

`deploy` 브랜치에 push하면 GitHub Actions가 `out` 폴더를 빌드해 `https://ej-pro.github.io` 주소로 배포합니다.
